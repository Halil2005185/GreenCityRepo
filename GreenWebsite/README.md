# GreenWebsite — الموقع العام

الواجهة العامة لمشروع المدن الخضراء: التعريف بالمشروع، البرامج والمبادرات،
الأثر الموثَّق، ودعوة الجهات إلى الشراكة.

مبني على Next.js 16 (App Router) وReact 19 وTailwind CSS 4، عربي وRTL
افتراضيًا، بنفس لوحة ألوان `GreenAdminDash` وخط IBM Plex Sans Arabic.

## التشغيل محليًا

```bash
cd GreenWebsite && npm install && cp .env.example .env.local && npm run dev
```

الموقع على `http://localhost:3001` — منفذ مستقل عن اللوحة (`3000`) والـAPI
(`4000`)، فيمكن تشغيل الثلاثة معًا.

| الأمر | الوظيفة |
|---|---|
| `npm run dev` | خادم التطوير على المنفذ 3001 |
| `npm run build` | بناء الإنتاج (`output: standalone`) |
| `npm run lint` | ESLint |
| `npm run typecheck` | فحص الأنواع بلا إخراج |

## البنية

```
app/                 المسارات (App Router)
  page.tsx           الرئيسية
  about/             عن المشروع
  programs/[slug]/   البرامج ومبادرات كل برنامج
  initiatives/[slug] المبادرات وتفصيل كل مبادرة
  impact/            الأثر ومنهجية القياس
  partners/          أنواع الشراكة وأشكال الدعم والشركاء
  join/              طرق المشاركة
  contact/           قنوات التواصل
  sitemap.ts         خريطة الموقع (ثابتة + من الـAPI)
  robots.ts          الفهرسة مسموحة — عكس اللوحة
components/
  layout/            الشريط العلوي والتذييل والشعار
  ui/                عناصر أساسية (زر، بطاقة، شارة، قسم، حالة فراغ)
  cards/             بطاقة مبادرة وبطاقة برنامج
  sections/          أقسام تقرأ الـAPI ويُعاد استعمالها بين الصفحات

  content/           نصّ الميثاق وتسميات الحالات — ثابت في الكود عمدًا
  api/               عميل الـAPI العام وأنواعه
```

## القاعدة الملزمة

لا يُكتب في الكود اسم مبادرة، ولا رقم هدف، ولا عدد مواقع، ولا اسم مؤشر،
ولا قائمة محافظات. كلها من قاعدة البيانات عبر `lib/api/public.ts`. راجع
[PLAN.md](../PLAN.md).

الثابت في الكود محصور في `lib/content/`: أنواع الشراكة الخمس وأشكال الدعم
السبعة (نصّ الميثاق) وتسميات الحالات — وهي عقود لا بيانات تشغيل.

## ما ينقص: مسارات الـAPI العامة

الباك‌اند اليوم يعرض `/api/admin/*` خلف مصادقة، ولا مسارات عامة. حتى تصدر،
تُرجع دوال `lib/api/public.ts` قيمًا فارغة وتعرض الصفحات حالة «لا بيانات»
بدل أن تنهار — الموقع يعمل كاملًا وتظهر فيه المحتويات التحريرية.

العقد المطلوب من `GreenBackend` (بلا مصادقة، قراءة فقط):

| المسار | يُرجع |
|---|---|
| `GET /api/public/programs` | البرامج النشطة |
| `GET /api/public/programs/:slug` | برنامج واحد |
| `GET /api/public/initiatives?program=&limit=` | المبادرات المنشورة |
| `GET /api/public/initiatives/:slug` | مبادرة بمؤشراتها ومواقعها |
| `GET /api/public/impact/summary` | مجاميع الأثر الموثَّق للمشروع |
| `GET /api/public/partners` | الشركاء الموافقون على إظهار اسمهم |

قواعد لا يجوز كسرها في هذه المسارات:

- المبادرة لا تظهر قبل إطلاقها (`ACTIVE` وما بعدها)، والمسودات لا تخرج.
- الأثر المعلن هو الموثَّق وحده: `verified_at IS NOT NULL` وبلا قيد عكسي.
- الشريك لا يظهر إلا بموافقة إظهار سارية.
- لا معرّفات مستخدمين ولا ملاحظات داخلية ولا قيم مالية في أي استجابة.

أشكال الاستجابة موصوفة في `lib/api/types.ts`. حين تصدر المسارات في
`openapi.json`، يُولَّد `types.gen.ts` كما في اللوحة ويُحذف الملف اليدوي.
