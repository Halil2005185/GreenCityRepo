# Typography

## IBM Plex Sans Arabic
IBM Plex Sans Arabic هو الخط الرسمي الوحيد المعتمد لمشروع Green Cities.

يُستخدم لجميع نصوص المشروع، بالعربية والإنجليزية، دون الحاجة إلى خط ثانٍ

## Font Weights
- Light — IBMPlexSansArabic-Light.ttf — وزن 300
- Regular — IBMPlexSansArabic-Regular.ttf — وزن 400
- Medium — IBMPlexSansArabic-Medium.ttf — وزن 500
- SemiBold — IBMPlexSansArabic-SemiBold.ttf — وزن 600
- Bold — IBMPlexSansArabic-Bold.ttf — وزن 700

**رابط التحميل:**  
[Google Fonts – IBM Plex Sans Arabic](https://fonts.google.com/specimen/IBM+Plex+Sans+Arabic)

## Weight Usage
- Bold / SemiBold: العناوين الرئيسية، أغلفة التقارير، الأرقام المهمة، والدعوات المهمة
- Medium: العناوين الفرعية، القوائم، أسماء الأقسام، والنصوص التوضيحية القصيرة
- Regular / Light: النصوص الطويلة، الشروحات، التقارير، ومعلومات التواصل

## Formatting Rules
- العنوان لا يتجاوز سطرين.
- تباعد الأسطر في النص العربي لا يقل عن 1.5.
- لا تُستخدم الأحرف الكبيرة المتباعدة في النص العربي
- النص العربي يُحاذى إلى اليمين دائمًا
- لا يُستخدم أي خط خارج عائلة IBM Plex Sans Arabic في المواد الصادرة باسم المشروع

## Fallback Fonts
عند تعذّر تثبيت أو تشغيل IBM Plex Sans Arabic على جهاز أو منصة، يمكن استخدام

- Tajawal
- Cairo

لا يُستخدم Arial أو Tahoma أو أي خط بديل آخر

## Notes
إذا كانت أسماء ملفات الخطوط مختلفة، يجب تعديل مسارات الخطوط في ملفات المشروع التي تستخدمها
